# Refleksi Praktikum TaskMahasiswa Offline

Dalam praktikum ini, saya mempelajari cara membangun aplikasi Android untuk mengelola tugas mahasiswa menggunakan Kotlin, Jetpack Compose, ViewModel, Repository, dan Room Database.

Tantangan yang saya hadapi adalah memahami hubungan antara tampilan aplikasi dan penyimpanan data lokal. Saya belajar bahwa UI sebaiknya tidak mengakses database secara langsung agar struktur kode lebih terorganisasi dan mudah dipelihara.

Penggunaan Room Database membantu aplikasi menyimpan data secara lokal sehingga tugas tetap tersedia setelah aplikasi ditutup dan dibuka kembali. Saya juga mempelajari pentingnya pengelolaan state agar perubahan data dapat ditampilkan kembali pada UI.

Melalui praktikum ini, saya memperoleh pengalaman dalam mengembangkan aplikasi offline, menguji fitur, menggunakan Git untuk mencatat perubahan, serta mengunggah proyek ke GitHub sebagai dokumentasi pengerjaan.

Ke depannya, saya ingin meningkatkan kemampuan dalam menyusun arsitektur aplikasi Android dan menulis pengujian yang lebih terstruktur.
